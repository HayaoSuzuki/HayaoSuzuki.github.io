# チューバ奏者の帰還

*2024-04-06 公開*

数年前まで、私は「チューバ買う買う詐欺」を繰り返していた。
常習犯と言っても過言ではない。
学部の同級生であり、熱心なチューバ奏者であるN氏に中古のチューバを提案されるも「うーんむにゃむにゃ」と適当にはぐらかしていた。
私には持論があった。
チューバを買う前に、チューバを運搬するための車を手に入れるべきではないか。
車を買う前に、自動車免許が必要ではないか。
つまり、チューバを買う前に自動車免許を取得するべきなのではないか。
完璧な三段論法である。
学部の論理学の単位を落とした割には三段論法を使いこなしているではないか。
完璧な論証に基づく持論。
とはいえ、いずれにせよ、先立つものがなければ袖は振れない。

ある日、東京都新宿区北新宿にあるTuba88にマイネル・ウェストン2144の中古が入荷した。
アメリカのチューバ奏者サム・ピラフィアンが使用したモデルである2145から5番ロータリーを取り除いたモデルである。
N氏はかねてよりB♭管よりもC管を勧めていた。
私にはC管がわからぬ。
中学ではヤマハのYBB-105とYBB-641II、高校ではドイツ製のB♭管、市民吹奏楽団ではYBB-321を吹いてきた、B♭をドと読む生粋のB♭管人間である。
N氏は力説する。
社会人になって以来、チューバから離れて久しい。
ならば、C管でも案外すぐに運指は覚えられるのではないか。
私は、重い腰を上げて、Tuba88の中村さんに連絡を入れるのであった。

新大久保駅。
以前はコリアンタウンと呼ばれていたが、今ではアジア各地の雰囲気が強い場所である。
健康診断で何回か来たことがあったが、何度来てもすごい街だなと感じる。
Tuba88へ。
N氏も楽器が気になるとのことで同席した。
2144の試奏を始める。
10年以上のブランクがあったが、楽器の持ち方はすぐにわかった。
音もそれなりに出た。
やはりB♭管の記憶が強いのか、運指と音の違和感が凄まじいものがあった。
Aの音程も気になった。
B♭管の記憶か、単に楽器の癖か。
音色はよかったというか、いい音がしていた、気がした。
それなりに悩んだ末に、2144を購入することにした。
てっきり発送するのかと思ったがここから担いで埼玉まで持ち帰ることになった。
チューバは重い。
20年以上前から知っていたが、改めてその重みを感じていた。
