# 気付いたら技術書翻訳者になっていた

*2025-10-05公開*

今はなき電通大C科（情報通信工学科）における学部3年の学科実験や学部4年の卒業研究では、数式処理システムMathematicaを使っていた。学科実験ではデジタルフィルタの実装、卒業研究ではグラフ理論の研究が目的であった。もっとも、卒業研究はまったくの理論だったので、論文の導入に必要となるグラフを生成する程度であった。

無事、卒業研究も終わり、博士前期課程（修士課程）に進学するタイミングで学科改組が行われて、慣れ親しんだC科から見知らぬJ専（総合情報学専攻）へ進んだ。進学してすぐに発覚したのは、J専攻の学生向けにはMathematicaのライセンスが付与されないことであった。昨今の大学は大学院重点化が進み、学部よりも研究科のほうが主役のような扱いを受けているにもかかわらず、大学院生向けのMathematicaのライセンスは付与されないのである。

なんてひどい大学だと思いつつ、現在の状況でも数学の研究を継続できるように、オープンソースを模索し始めた。最初に使い始めたのはMaximaである。無料でここまでできるのはすごいなと思う一方で、LISPベースの言語は不慣れで、パッケージの範囲を超えることをやろうとすると難しかった。次に使い始めたのがSage Mathである。Sage Mathはノートブック上で数式処理ができるすごいものであった。難点はWindowsで動作しないことであり、研究室の計算機も所有する計算機もWindows機であったので、動かすまでが大変であった。デュアルブートでLinuxとWindowsを同居させて動かしていた。次第にデュアルブートが面倒になり、数式処理ライブラリであるSymPyのみを使うようになった。SymPyならばWindows上でも満足に動作するので、自分がやりたいことはSymPyを使えば十分であった。もともと、Sage Mathは各種数学ソフトウェアをPythonで統合したものであり、SymPyもまたPythonで実装された記号計算ライブラリであった。つまり、Pythonというプログラミング言語はSage MathやSymPyを使うために出会った言語であった。

Sage MathやSymPyを使うための言語としてPythonを使い始めたが、すぐにその利便性に気付いた。学部ではPascalやC言語を学んだが、それを普段の作業で使うのは大変であった。一方、Pythonは簡単に使えるので、Windows上で使えるシェルスクリプトとして研究以外にも使うようになった。ファイルのリネームや変換処理などの用途で使うようになった。簡単に使えるので、学部の後輩にPythonを教えて卒業研究の計算機実験をPythonでやってもらったり、自分の修士論文において数値計算をSymPyで計算してみたりと、少しずつPythonを使い始めていた。当時読んでいた本は『Pythonチュートリアル』『初めてのPython 第3版』であった。『エキスパートPythonプログラミング』は難しくて読めなかった。

大学院修了後、今風に言えばSESの会社に入社した。当然、周囲にはPythonを使うエンジニアは皆無であり、常駐先の方には「Pythonっておもちゃの言語でしょ」と言われたりもした。それでも、その常駐先の方は私がPythonを使って仕事を進めることを認めてくれたのである。最初に入った会社は、世間一般の社会常識を学ぶ場としては良かったが、ソフトウェアエンジニアのキャリアを考えると厳しい環境であった。もっとも、その会社特有の問題ではなく、SESを前提とする企業の構造的な問題である。入門書以上のレベルを取り扱うPythonの和書は存在せず、『エキスパートPythonプログラミング』は依然として難しく、書店で見かけた『Python 3 プログラミング徹底入門』を読み進めていた。

PyCon JP 2014が行われると耳にした。それほどお金に余裕はなかったが、せっかくなので参加することにした。参加費は1万円であり、当時の自分にとっては大金であった。交通費も馬鹿にならない。カンファレンスは昔参加したTexConf 2013以来である。TexConf 2013でも自分の能力のなさを痛感するイベントであったが、PyCon JP 2014も同じような結果となった。会場近くにあった宗谷を眺めに行った程度に、PyCon JPに精神をやられていた。発表者が何を言っているのかがわからないのである。もちろん、英語なのでよくわからないというのもあるが、日本語だとしても発表者が立っている前提に到達していないのである。『Python文法詳解』のサイン会が行われたのもPyCon JP 2014であるが、サインをもらった形跡はなかった。確かこの時期に購入したはずだが、サインをもらう気力すら残っていなかったであろう。

2015年2月から『Python文法詳解』の読書会「Python文法詳解を詳解する会」が新宿で行われていた。私は2015年5月20日の第4回から参加するようになった。勉強会に行くから仕事を切り上げる、という柔軟性がある職場ではなく、かといって業務で行くとなるとそれは面倒であったので、午後半休を使って勉強会に参加していた。業務後では間に合わないからである。PyCon JPも有給休暇を使っていた気がする（だから、カンファレンスをすっぽかして宗谷を見学するなどできるのであるが）。読書会は非常に面白く、会場近くのハブにおける打ち上げも面白かった。普段の業務では閉じた環境で仕事をすることが多く、その環境の外にいる人たちとの交流がその当時の活力になっていた。

『Effective Python』という本が2015年の3月に発売された。入門書の先に存在するPythonの本に飢えていた。紀伊國屋に発注していた『Effective Python』が届いた。さっそく読み始めた。当然、英語であり、すんなり読み進めることはできなかったが、文学ではなくPythonの本なので、英語の壁を超えた後は面白く読めた。『Effective Python』は英語であり、このままの状態では日本に広まることはないだろう。ならば、自分で翻訳して世に問えば広く読まれて、Pythonが日本でも広まるのではないか。そう考えた。2015年当時、Pythonは日本ではマイナーな言語であった。一部のマニアが使っている言語であり、常駐先の方の「Pythonっておもちゃの言語でしょ」という発言は至極当然であった。入門書は何冊か存在するが、その先は荒野であった。著作権には翻案という概念があり、翻訳は翻案に該当する。私的利用ならともかく、勝手に翻訳して世に問う行為は当然著作権に違反する。しかし、それでも翻訳してみたかった。原著者が用意した『Effective Python』のWebサイトに掲載されていたサンプルを翻訳して、原著者のBrettさんにTwitterのDMを送り、翻訳を掲載していいかを尋ねた。結果としてはNGであったが、そのDMで邦訳が計画されていることを知った。翻訳は掲載できない。だが、読んだ感想は掲載できる。項目を翻訳した後に、その感想をブログに書き始めた。項目37まで翻訳を続けた。

『Effective Python』の私家版の翻訳を進めていたところ、石本さんから連絡があった。『Effective Python』邦訳初版の翻訳者である黒川さんが私のブログを読み、一度お会いしたいというお話であった。連絡が来た時は一体何を言っているのかよくわからなかった。急遽午後半休を取り、有楽町線の市ヶ谷駅から四谷坂町にあるオライリー・ジャパンに向かった。内容としては、邦訳初版のレビュアーとして参加してほしいということだった。二つ返事で承諾した。邦訳が計画されていることは知っていたが、まさかその企画に関わることになるとは思ってもいなかった。翻訳の原稿を読み始めたタイミングで『Effective Python』に関するエントリの更新を止めた。2016年1月、『Effective Python』邦訳初版が発売された。巻末に査読者として名前と経歴まで掲載していただいた。 

その後も、オライリー・ジャパンから出版されるPython本の査読を行ったり、コミュニティ経由で翔泳社やインプレスの本の査読、黒川さんの縁で朝倉書店の本を査読したりした。翔泳社やインプレスの場合、翻訳ではなく書き下ろしなので微妙に査読の方向性が異なるのと、複数人で読むのでリズムが合わないことがあった。複数人で査読するにせよ、自分は1人で文章に向き合って読むほうが向いていたのであろう。朝倉書店では、ちょうど風邪をひいていて調子がすこぶる悪く、結果として次に続くことはなかったが、索引も査読の対象であることを学ばせてもらった。

2020年2月、『入門 Python 3 第2版』の監訳の依頼が舞い込んできた。邦訳初版の監訳者が多忙であり、そこで白羽の矢が立ったのである。連絡が来た時は本当にびっくりした。当時在籍していた会社の会議スペースで電話を受けたことを覚えている。その時にやっていた仕事はもはや覚えていない。『入門 Python 3』は長大な本であり、監訳といえども1年掛かってしまった。その分、書店に自分の名前が入った本が平積みされている光景は学部生や院生、仕事を始めた頃の自分には想像できなかっただろう。そして、『Python Distilled』で翻訳に挑戦、『Effective Python 第3版』の翻訳も手がけることになった。2015年に抱いていた夢が、2025年に現実になった。Pythonはメジャーな言語となり、日本に広まっていた。それでも、自分で翻訳して世に問いたい思いは変わっていなかった。

こうして、私は、気付いたら技術書翻訳者になっていたのである。
